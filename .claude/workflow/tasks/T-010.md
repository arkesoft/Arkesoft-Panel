### Tip tasarımı

`ThemeManifest` = `z.strictObject({ id, name, version, sdkRange, templates, settings, migrations })`
`id` basit slug `^[a-z][a-z0-9]*(-[a-z0-9]+)*$` · `version`/`sdkRange` **yalnızca biçim** doğrulanır
⚠ Manifestte **servis edilen URL yolu / önbellek başlığı / `publicPath` / `assetsPrefix` alanı YOK**
`ThemeAssetRef = { source: 'theme-asset'; path: string }` — mutlak URL, baştaki `/`, `..`, `\` **reddedilir**

`templates` **DİZİ** (anahtarlı nesne değil) ⚠ gerekçe: `'404'` integer-benzeri anahtar olarak JS semantiğiyle **listenin başına taşınırdı** → determinizm bozulurdu. Bedeli: tekrarlı `type` mümkün → `THEME_TEMPLATE_DUPLICATE` **dizi şeklinin zorunlu sonucu, kapsam genişlemesi değil**.
**Zorunlu şablon kümesi: `home` + `404` (V6)** ⚠ gerekçe: CLAUDE.md §3 ağacında `packages/themes/corporate/` var; `cart`/`product`'ı zorunlu kılmak onu **temsil edilemez** yapar. Ayrıca kümeyi **genişletmek major**, **daraltmak minor** → bugün küçük küme tek güvenli yön.

Sekiz ayar ilkeli `z.discriminatedUnion('type', …)`, her kol `z.strictObject`. Ortak sunum üstverisi `{ key, type, label, description?, order? }` (ileride `packages/ui` şema→form motoru theme-sdk **majoru olmadan** tüketebilsin).
⚠ **`group` derinlik-1** (çocukları `group` içermez, V5) — özyinelemeli şema `z.toJSONSchema()`'yı `$defs` + `__schemaN` otomatik adlarına zorlar. İç içe grup ileride **minor**.
⚠ Başka ilkelde `group?: string` alanı **YOK** — içerme yalnızca `group.children` ile.
⚠ **`assertNever` 5. kopya** — paket-yerel `src/assert-never.ts`. Terfi **bilinçle reddedildi** (yeni paketler-arası kenar; borç 1583 zaten terfi önermiyor). `solid` bunu yazılı karar olarak görsün.

### Hata tasarımı

15 kararlı kod: `THEME_MANIFEST_UNKNOWN_KEY` · `THEME_MANIFEST_INVALID` · `THEME_ID_INVALID` · `THEME_SDK_RANGE_INVALID` · `THEME_TEMPLATE_UNKNOWN` · `THEME_TEMPLATE_MISSING` · `THEME_TEMPLATE_DUPLICATE` · `THEME_SETTING_KEY_UNSAFE` · `THEME_SETTING_INVALID` · `THEME_ASSET_REF_INVALID` · `THEME_MIGRATION_MISSING` · `THEME_MIGRATION_GAP` · `THEME_MIGRATION_DUPLICATE` · `THEME_MIGRATION_CYCLE` · `THEME_MIGRATION_RESULT_INVALID`

`ThemeContractIssue = { code, path, message }`; `path` → `templates[2].slots[0].id` biçimi (`src/paths.ts`).
**Dönüş ayrımlı birleşim** (`{ ok: true, … } | { ok: false, issues }`) ⚠ **CLAUDE.md §4'ten bilinçli sapma** — §4 "hata fırlat, `null` döndürme" diyor; ayrımlı birleşim `null` **değil** ve çağıranı tahmine zorlamıyor (`ok` discriminant'ı derleyici tarafından zorlanır). Zorunlu çünkü çok issue dönüyor ve `validateThemeSettings` **uyarıyla başarı** dönmek zorunda (AC5). Ergonomi için fırlatan ikiz: `assertThemeManifest()`. **`solid` bu sapmayı bilerek değerlendirsin.**
**Mesaj dili: Türkçe geliştirici metni, i18n anahtarı DEĞİL.** Kararlı makine sözleşmesi `code`; `message` değişmek **patch**, `code` değişmek **major**. Son kullanıcıya çeviri `code` → i18n eşlemesiyle **uygulama** katmanında (v0.0.21). Zod'un `tr` locale'i **kullanılmaz** (global `z.config()` yan etkisi saflığa aykırı). Ölçülebilir güvence: `satisfies Record<ThemeContractErrorCode, string>` → kod eklenip mesaj eklenmezse **derleme düşer**.
