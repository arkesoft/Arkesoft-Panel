## İstek

ROADMAP `v0.0.18` — Çoklu dil ve para birimi altyapısı (`ROADMAP.md:1192`)

**Hedef:** Metin ve para biçimlendirmesi tek merkezden gelsin (içerik çevirisi 1.5.0'da).

**Kapsam:**

- [ ] `packages/i18n`: mesaj kataloğu formatı, `tr-TR` varsayılan, `en-US` ikinci dil
- [ ] Admin ve storefront için çeviri yükleyicisi, eksik anahtar tespiti
- [ ] `Money` değer nesnesi: tamsayı kuruş, para birimi kodu, toplama/çarpma, yuvarlama kuralları
- [ ] Biçimlendirme yardımcıları: para, tarih, sayı (Intl üzerinden)
- [ ] `Currency` ve `ExchangeRate` tabloları (TRY varsayılan)
- [ ] Float ile para tutmayı yasaklayan ESLint kuralı

**Dokunulan paketler:** `packages/i18n`, `packages/db`, tüm `apps`
**Kabul kriteri:** `pnpm --filter @arkesoft/i18n test` yeşil; `Money` testleri yuvarlama ve
para birimi uyuşmazlığı hatalarını kapsar; eksik çeviri anahtarı CI'da uyarı üretir.
**Bağımlılık:** v0.0.7 ✅ (tamamlandı 2026-11-01, 6/6 kutu)
**Tahmini büyüklük:** M

⇒ **Üçüncü yol ADR'de yazılı.** `message` alanı **gerçek tüketici kazanır**, ADR-0010 §3.6
**ihlal edilmez**:

| Soru | Karar |
| --- | --- |
| **(1) Tüketici kim?** | `apps/admin` **ve** `apps/superadmin` — ikisi de bugün var |
| **(2) Defter nerede?** | **`packages/errors/src/error-message-keys.ts`** — ⚠ **zorunluluk, tercih değil**: defter `i18n`'de olsaydı `error-body.ts`'in iki jenerik fabrikası oradan okurdu ⇒ `errors → i18n` **ve** `i18n → errors` = **DÖNGÜ** (CLAUDE.md §3 yasak). M7'nin borç notu doğru adresi vermiş |
| **(3) Bağımlılık yönü?** | `zod ← errors ← i18n ← {admin, superadmin}` · `db → i18n` **devDependency** · ⭐ döngü **üretilemez** çünkü `errors` hiçbir iç pakete bağımlı değil |

**`PanelError` kapalı küme altında anahtar taşır:**

```ts
readonly messageKey: ErrorMessageKey | null   // string DEĞİL
```

`normalize-panel-error.ts` → `errorMessageKeySchema.safeParse(body.message)`; küme dışındaki
**her** değer (ham sunucu metni dahil) `null`'a elenir. ⭐ `extractAllowlistedFields`'in
(`:69-86`) kardeşi, **aynı dosyada, aynı tek filtreleme noktasında** — T-019/S8'in `fields`
kanalında kurduğu desenin **birebir aynısı** ⇒ `panel-error.ts:9-11` garantisi **gevşemiyor**,
**kapalı kümeye devrediliyor**.

**Çözümleme merdiveni** (iki panelde aynı, `switch` + `assertNever`):

```
unknown                                  → jenerik Türkçe
messageKey !== null                      → resolveMessage(messageKey)       ← telden
messageKey === null, code defterde       → resolveMessage(ERROR_MESSAGE_KEYS[code])
code sağlayıcı tablosunda (Better Auth)  → sağlayıcı metni   ← ADR-0010:232'nin "ikinci tablo"
aksi                                     → jenerik Türkçe
```
