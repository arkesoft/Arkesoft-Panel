## Orkestratör'ün ön ölçümü (2026-11-19)

### ⚠⚠ Borcun tarifi EKSİK — asimetri iddia edildiği yerde değil

`D24` satırı bunu *"`Referer`'a düşüş dalının güvensiz-metot muafiyeti yok"* diye
tarif ediyor. Kod okundu (`detectViolationAgainstTrustedOrigins`):

```ts
const secFetchSite = singleHeaderValue(headers, 'sec-fetch-site')
if (secFetchSite === 'cross-site') return 'cross_site_fetch_metadata'

const origin = singleHeaderValue(headers, 'origin')
if (origin !== undefined) {
  return trustedOrigins.includes(origin) ? undefined : 'origin_mismatch'   // ⚠ metot kontrolü YOK
}

const referer = singleHeaderValue(headers, 'referer')
if (referer !== undefined) {
  return isTrustedOrigin(referer, trustedOrigins) ? undefined : 'origin_mismatch'  // ⚠ metot kontrolü YOK
}

const isUnsafeMethod = !SAFE_METHODS.has(method.toUpperCase())   // ⭐ muafiyet YALNIZCA burada
const hasCookie = singleHeaderValue(headers, 'cookie') !== undefined
if (isUnsafeMethod && hasCookie) return 'missing_origin_with_cookie'
return undefined
```

⇒ Muafiyet `Origin` dalında **da** yok. Asimetri `Origin` ↔ `Referer` arasında
**değil**; muafiyet yalnızca **üçüncü dalda** (ikisi de yok) var. `D24`'ün tarifi bu
yönden düzeltilmeli.

### ⚠ Dosya başı yorumu bu konuyu ZATEN tartışmış (`:29-37`)

> *"**Yalnızca GÜVENSİZ metotlarda** (`GET`/`HEAD`/`OPTIONS` DIŞI) uygulanır — modern
> tarayıcılar `Origin`'i SADECE çapraz-orijin GET isteklerinde veya GÜVENSİZ
> metotlarda ekler (Fetch spesifikasyonu); AYNI-orijin bir `GET /auth/sessions`
> çağrısı `Origin` TAŞIMAYABİLİR ve bu NORMALDİR — bu dalı GÜVENSİZ metotlara
> sınırlamak, salt-okunur bir uca gerçek bir kullanım kırmadan FAIL-CLOSED
> semantiğini EKLER."*

⭐ Ama bu cümle **üçüncü dalı** tarif ediyor, `Origin`/`Referer` dallarını değil. Yani
mevcut davranış bilinçli bir karar **olabilir** — "eksik muafiyet" olarak okumak
peşin kabul olur.

### ⚠⚠ pm'in ölçtüğü ÜÇ ŞEY — borcun tarifini ikinci kez düzeltiyor

### `K2` mekanizması — yeni env alanı

`ADDITIONAL_TRUSTED_ORIGINS` — **opsiyonel**, `.default('')`, **virgülle ayrılmış TAM EŞLEŞMELİ**
orijin listesi. ⭐ Biçim emsali bilinçli: `SUPERADMIN_IP_ALLOWLIST` ile **aynı sınıf**.
Ad *"ADDITIONAL"* çünkü semantiği **toplamalı**.

**Açılışta fail-fast Zod doğrulamaları** (Türkçe mesaj): her parça trim, boş parçalar atlanır
(sondaki virgül hoş görülür); her parça için (1) `http`/`https` şemalı mutlak URL; (2) ⚠ joker
karakter **yok** — ⚠⚠ bu kontrolün jetonu **çalışma anında birleştirilir** (AGENT_BASELINE §5
literal-jeton kuralı: mekanik tarama eklenirse **kendi kontrol kodunu** bulgu sanmamalı);
(3) kullanıcı adı/parola bileşeni **yok**; (4) `/` dışında yol/sorgu/fragment **yok** (⭐ sessiz
"orijine indirme" yerine **gürültülü ret**; mevcut `SUPERADMIN_BASE_URL`'in orijine indirme
davranışı **değişmiyor**, yeni alan **daha katı**); (5) kardinalite üst sınırı **8**.

⚠⚠ **Çapraz alan fail-closed kontrolü** (`trusted-origins.ts` içinde, `APP_BASE_DOMAIN` ile):
bir girdinin hostname'i `APP_BASE_DOMAIN`'in **tek etiketli** alt alan adıysa **ve** etiket
`RESERVED_SUBDOMAINS` üyesi **değilse** → **fırlatılır** (kiracı orijini yasağı).
`panel`/`superadmin`/`api`/`www`/`app` geçer, `kiraci` **geçmez**.

**Türetme** (`resolveTrustedOrigins`, ⭐ **imzası DEĞİŞMİYOR** ⇒ `R7` tasarımla kapalı):
sıra `[origin(AUTH_BASE_URL), origin(SUPERADMIN_BASE_URL)?, ...origins(ADDITIONAL)]`,
**tekilleştirme** ile (⭐ `toHaveLength` iddiaları anlamlı kalsın).

⚠⚠ **Bağlayıcı çağrı-yeri kuralı:** fonksiyon artık **fırlatabilir** ⇒ yalnızca **açılış
zamanında** çağrılabilir. `SameOriginGuard` türetmeyi `canActivate`'ten **yapıcıya** taşır.
⭐ Üç kazanç: istek başına `new URL()` ayrıştırması **artmaz, HİÇ yapılmaz** (bugün istek başına
1-2 kez); fail-fast açılışa çekilir; `solid`'in "aynı türetme her istekte" eleştirisi kapanır.
